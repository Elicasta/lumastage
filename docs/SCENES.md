# Scene identity and energy variants

LumaStage treats a Scene as a reusable visual identity. Energy variants are parameter overrides inside that identity, not duplicated scenes.

A scene may define LOW, MID, HIGH and PEAK variants. LumaStudio section metadata feeds the Energy Director, which can select an appropriate band while the operator retains manual control. Beat modulation is layered on top of the selected band rather than replacing it.

This prevents a common live-visual failure mode where every musical section changes to an unrelated look. A worship song can remain inside one visual world while movement, bloom, particle rate, typography opacity and other approved parameters rise and fall with the arrangement.

The first production collection includes Apostolic Day 2026 / Established Red as a concrete design target.
